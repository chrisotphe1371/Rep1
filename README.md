# Badminton Player Finder

Application web de recherche de joueurs de badminton avec filtres par pays et catégorie.

## Fonctionnalités
- recherche par nom, club, pays ou catégorie
- filtres dynamiques
- cartes de profils joueurs
- compteur de résultats et note moyenne

## Lancer localement
Ouvrez simplement le fichier `index.html` dans un navigateur, ou servez le dossier avec un petit serveur web local.

## Stack
- HTML
- CSS
- JavaScript
